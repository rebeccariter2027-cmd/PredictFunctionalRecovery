# SCI-Prediction
This is the source code utilized for computational modeling and data visualization in the manuscript Predicting Clinical Functional Recovery Following Spinal Cord Injury from a Porcine Model. It was adapted from the GitHub Repository TransCompR (https://www.science.org/doi/10.1126/scisignal.aay3258).

The main code used in the manuscript is titled TransCompR_Logistic.ipynb. Use of other classifiers were explored in the Supplemental Figures and uploaded under their respective names.
